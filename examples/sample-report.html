Methodology

Scope: none — demo dataset — 50,000 in-scope records. "Recent" = CreatedDate in the trailing 365 days (8,000 records), used to check whether a field is still being written to on new records versus only present on old ones.

Population was measured with SOQL COUNT(field) aggregates, batched across fields. Boolean fields SOQL won't aggregate directly were measured instead via WHERE field = true — those show an all-time rate only, no recent split.

  • Fields flagged "needs manual review" are long text areas, multi-select picklists, or encrypted strings — SOQL can't filter or aggregate them at all. A data export is required to check them properly.
  • "Legacy" fields are populated all-time but have fallen off sharply on recently created records — still present, no longer being set.
